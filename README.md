# Шашки онлайн

Русские шашки 8×8: игра вдвоём по ссылке или на одном устройстве. Интерфейс на русском, адаптирован для телефона и компьютера. Без регистрации, рекламы и стороннего игрового сервера.

**Играть:** https://shashki-online.kkoallqq.workers.dev

**Репозиторий:** https://github.com/skweye/shishki-online

## Возможности

- Приватные комнаты по приглашению: создатель играет белыми, второй игрок — чёрными.
- WebSocket-синхронизация, серверная проверка каждого хода и защита от устаревших команд.
- Обязательное взятие вперёд и назад, цепочки ударов, летающие дамки, превращение во время взятия. Побитые шашки остаются препятствиями до завершения хода.
- Подсветка ходов, история, поворот доски, сдача, предложение ничьей, реванш по согласию обоих игроков.
- Ничья при троекратном повторении позиции. Специальные турнирные лимиты эндшпиля не реализованы; это любительская версия без часов.
- Восстановление соединения и позиции после перезагрузки. Локальная партия сохраняется в браузере, онлайн-партия — в Durable Object.

## Запуск

Нужны Node.js 22+ и npm.

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:8787. Для проверки игры вдвоём используйте два разных браузера или обычное и приватное окно: место игрока привязано к localStorage браузера. Повторное открытие комнаты в том же браузере восстанавливает ваше место и отключает старую вкладку.

## Проверки

```bash
npm run check
npm test
npm run build
```

Для интеграционных проверок запустите `npm run dev` в отдельном терминале, затем:

```bash
npm run test:integration
```

Проверяются два WebSocket-клиента, синхронизация ходов, закрытая комната, авторизация, чужой ход, устаревшая позиция, повторное подключение, ничья, реванш и сдача. Для проверки опубликованной игры задайте `TEST_BASE_URL` с адресом Worker; тест создаст отдельную комнату, которая удалится по сроку хранения.

## Cloudflare

Приложение использует **Cloudflare Workers + Static Assets + SQLite Durable Objects**. Обычный GitHub Pages не подходит для онлайн-режима: нужен Worker с WebSocket-комнатами.

```bash
npx wrangler login
npm run deploy
```

При необходимости измените `name` в `wrangler.jsonc`. Durable Object создаётся миграцией `v1` автоматически. Внешняя база данных и дополнительные секреты для самого приложения не нужны.

Документация: [WebSockets и Durable Objects](https://developers.cloudflare.com/durable-objects/best-practices/websockets/), [статические файлы Worker](https://developers.cloudflare.com/workers/static-assets/binding/).

## GitHub и автоматическая публикация

В репозитории есть две GitHub Actions:

- `ci.yml`: проверка синтаксиса, правил, сборки и настоящих онлайн-комнат при push и pull request.
- `deploy.yml`: те же проверки и публикация ветки `main` на Cloudflare; также доступен ручной запуск.

В **Settings → Secrets and variables → Actions** добавьте:

| Secret | Значение |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare API token с разрешениями Workers Scripts: Edit, Account Settings: Read для нужного аккаунта |
| `CLOUDFLARE_ACCOUNT_ID` | ID вашего Cloudflare-аккаунта |

Токен создаётся в Cloudflare → My Profile → API Tokens. Используйте шаблон Edit Cloudflare Workers и ограничьте доступ нужным аккаунтом. До добавления секретов workflow выполняет проверки и пропускает публикацию. Храните секреты только в GitHub Secrets; не добавляйте их в код.

Для нового репозитория, если origin ещё не настроен:

```bash
git remote add origin https://github.com/YOUR_NAME/shishki-online.git
git push -u origin main
```

## Хранение и ограничения

- Комнаты доступны знающим код. В комнате ровно два места, зрителей и подбора случайного соперника нет.
- Для доступа к месту используется случайный секрет, сохранённый в localStorage. Ссылка приглашения содержит только код комнаты. Очистка данных браузера теряет доступ к месту; аккаунтов и восстановления через почту нет.
- Сервер не доверяет клиентской доске: проверяет роль, очередь, ревизию и допустимость каждого хода.
- Комната удаляется через 7 дней после последнего действия. Уход со страницы не означает сдачу.
- Для крупного публичного запуска стоит настроить ограничения частоты создания комнат на Cloudflare. Сейчас ограничен размер запросов, частота игровых команд и число соединений на игрока; глобального лимита комнат нет.
- Единственный внешний ресурс интерфейса — шрифт Google Fonts; при его недоступности используется системный шрифт.
- `sharp` в инструментах разработки закреплён через override на исправленную версию 0.35.5+.
