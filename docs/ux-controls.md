# UX: действия и состояния

Экран партии строится вокруг поля: название, статус, часы и игроки над ним; история и чат в одной боковой панели; под полем только управление режимом и переход после завершения. На узком экране панель переходит под поле.

Меню партии не меняет правила, протокол комнаты, сохранения, расчёт опыта и наград.

## Динамические действия

| Элемент | Контекст и расположение | Приоритет / решение |
|---|---|---|
| Клетки доски и фигуры | На самом поле; доступны разрешённые ходы | Прямое управление; стандартные стили кнопок их не затрагивают |
| Бильярд: удар | Свой ход, прицеливание, без анимации | Primary под столом; ЛКМ и колесо сохранены |
| Бильярд: переставить / отменить | Только биток с руки; рядом с ударом | Secondary; координаты появляются только при размещении |
| Бильярд: поставить по координатам | Только размещение битка | Secondary рядом с X/Y |
| Нарды: бросить | Только свой бросок, в центре доски | Primary; скрыто при чужом ходе и при анимации |
| Нарды: вывести | Есть доступный вывод выбранной фишки | Secondary под доской; счёт выведенных фишек остаётся у игроков |
| Нарды: отменить выбор | Фишка выбрана | Ghost рядом с выводом |
| Нарды: выбор кости | Выпавшие кости | Прямой выбор; использованные значения сохраняются для понимания хода |
| Домино: взять с базара / пропустить | Нет разрешённого хода; зависит от наличия базара | Одна из двух кнопок, никогда обе сразу |
| Домино: показать / скрыть руку | Передача устройства в локальной игре | Открытие — Primary, скрытие — Ghost; приватность сохранена |
| Домино: следующий раунд | Только завершённый раунд, не завершённый матч | Primary; ожидание согласия отображается отдельно от ходов |
| Морской бой: случайная расстановка / поворот | Этап расстановки, рядом с доком | Secondary; перетаскивание и колесо сохранены |
| Морской бой: вернуть корабль / очистить | Только если есть что вернуть / очистить | Secondary / Danger; пустые действия убраны |
| Морской бой: флот готов | Этап расстановки, под полем | Primary; счёт кораблей поясняет доступность подтверждения |
| Морской бой: показать / скрыть поле | Локальная передача устройства | Контекстное открытие / Ghost, сохранена приватность |
| Кейс: открыть на карточке | Есть монеты, наградный кейс или полный доступ | Secondary; яркое подтверждение только в окне кейса |
| Инвентарь: посмотреть / выбрать | Только предметы пользователя | Ghost / Secondary; у выбранного предмета статус вместо кнопки |
| Админ: права, полный доступ, монеты | Только разрешённые текущей ролью операции, в строке пользователя | Подтверждение в отдельной форме; серверные ограничения сохранены |

## Удалённые дубли

- Вторые «Создать комнату» и «Войти по коду» из боковой панели: используются только главная форма и вход по приглашению. Неудачное приглашение возвращает к этому единому сценарию.
- Отдельный «Покинуть комнату», дублировавший возврат: выход через «На главную» с тем же сохранением и подтверждением.
- Второе «Посмотреть доску» в результате: осталась кнопка закрытия с этим доступным названием.
- Повторяющие статус лозунги и постоянные подсказки: название и ход над полем, инструкция раскрывается возле управления.

## Проверки

DOM-тест запускает все восемь режимов и проходит ход, сброс, сдачу, результат, реванш, создание комнаты, подключение, чат, чужой ход, предложение ничьей и отключение. Отдельные проверки покрывают меню с клавиатуры, вкладки, непрочитанные сообщения и сохранение раскрытого приглашения при обновлениях. Визуальная проверка в браузере не выполнялась.
